When planning an overland trip, there are a million things to think of. Here we tackle two aspects of trip planning:

  • when is a good time to go? This is easy to find information, but interactive overviews are rare
  • what about the paperwork? Are the borders even open? Can you drive there at all? How long can you stay. This is hard to find information, and it changes all the time.

Currently all the info is just sourced from Claude, so take it with a grain of salt. If you have any corrections, post an issue or do a pull request.

This site is open source and the data behind it will always remain open source.
